## 团队协作方式

本页是纯静态页面，标注保存在**各自浏览器本机**（localStorage），多人之间不会自动互通。

1. 打开页面，先在右上角填「你的名字」
2. 逐项展开功能点，设置团队状态、填负责人、写备注（自动存本机）
3. 改完点右上角「导出 JSON」，发给同事
4. 同事打开页面点「导入」即可看到你的标注

导出格式支持 JSON（互传标注）、CSV（进 Excel）、Markdown（进 Wiki），均带「标注人」署名列。

需要多人实时同屏协作，请把 CSV 导入腾讯文档或飞书表格。
