1概览与原则

本规范约束智慧物业 V2 全部页面的视觉与交互基线。技术栈已确定：Vue 3.4 + Vite 5 + Element Plus 2 + Vue Router 4 + ECharts 5。

一致

同一含义在任何页面用同一种颜色、同一种控件、同一种文案。例如「逾期」永远是 #F56C6C，不会在 A 页红、B 页橙。

克制

一屏不超过 6 个 KPI、4 张图表。配色不超过 2 个色系。装饰性元素一律不加。

可行动

看板上每个数字都能点击并带筛选；每张看板最后一段必须是风险清单或待办，能直接派任务。

可扩展

所有视觉值走 Token，不写死。改一处 CSS 变量，全站生效。

本规范包含

色彩（品牌 / 语义 / 业务状态 / 图表色序）字形与字号阶梯 间距与圆角布局骨架与页面结构8 类组件规范 ECharts 配置基线文案与数字格式接入方式

三条硬约束（违反会导致返工）

  • 禁止在页面里硬编码颜色：一律用 CSS 变量或 tokens.css 中定义的语义变量；图表颜色走 echarts-theme.js。
  • 禁止为了「好看」引入新组件库：Element Plus 2 已有的组件不得替换；确实缺失的先提申请再引入。
  • 禁止按页面写样式：所有可复用的视觉模式必须先抽成组件，再在页面里引用。

7图表规范

所有图表通过 echarts.init(el, 'wy') 初始化，主题见 echarts-theme.js。页面内禁止硬编码颜色、字号、网格间距。

折线图 · 趋势（近 7 日工单量）
柱状图 · 对比（子系统在线率 %）
环形图 · 构成（资产构成，中心放总数）
仪表盘 · 完成度（比率型指标）

图表选型

要表达什么用什么禁止
随时间变化折线图（≤7 系列）；时间轴固定 5~12 个点超过 12 个点用折线堆叠成一片
同类项对比横向条形图（名称长时）或柱状图用饼图表达对比
占比构成环形图，中心放总数，≤5 段超过 5 段（其余归「其他」）
单个完成度仪表盘 / 进度条用数字卡片却不给目标值
两个量的关系散点图双 Y 轴（极易误读，确需时必须左右轴都标注单位）
空间分布热力图（楼栋 × 楼层）用表格填色代替
流程转化漏斗图（招聘、派单转化）用多个数字卡片摆一排

通用配置

项规则
标题写在卡片 H3 上，不用 ECharts 自带 title（避免两套字体）
图例顶部右侧；单系列时隐藏图例
网格containLabel: true，left/right 8px，top 32px
坐标轴值轴隐藏轴线只留分割线；类目轴隐藏刻度只留轴线
单位写在 Y 轴 name 或 tooltip 后缀，不写进系列名
Tooltip白底 + 1px #EBEEF5 边 + 轻阴影，圆角 6px
热力色阶用 heatColor() 固定分段，不按当期最大最小值自适应，否则跨月不可比
空数据图表区用 el-empty 覆盖，不在图上写「暂无数据」
响应式容器 resize 时 chart.resize()；卡片销毁时 dispose()
最容易出错的一条：门禁统计是人次、车场统计是车次，二者量纲不同，不能相加成「今日通行 X 次」。同理，空置率的分母不含车位与配套用房。
